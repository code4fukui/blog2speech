# blog2speech

> 日本語のREADMEはこちらです: [README.ja.md](README.ja.md)

Generate speech audio files from Taisuke Fukuno's blog.

## Features
- Generate speech audio files from Taisuke Fukuno's blog posts
- Supports multiple voice styles

## Requirements
- OpenAI API key set in the `.env` file

## Usage
```sh
deno run -A blog2speech.js 4325 echo
```

## Data / API
- OpenAI API
- Taisuke Fukuno's blog (Rensa)
